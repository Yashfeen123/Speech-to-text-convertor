# Speech-to-Text Converter

A lightweight web application built with Streamlit that transcribes uploaded audio files into text.

## Tech Stack
* **Python**
* **Streamlit** (Web framework)
* **SpeechRecognition** (Audio transcription library)

## Features
* Clean, interactive web interface for uploading audio files.
* Automatically processes and transcribes speech into readable text.
* Easy to run locally with simple configuration steps.

## How to Run

1. Clone this repository:
```bash
git clone https://github.com/Yashfeen123/Speech-to-text-convertor.git
```
2.Install the required packages:
```bash
pip install -r requirements.txt
```

3.Run the Streamlit application:

```
  streamlit run stt.py
```
